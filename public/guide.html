1 API Key Architecture & Database Persistence

Every operator who opens the console or signs in via Discord is automatically allocated an isolated user account in the central SQLite database (data/unblocker.db).

Database Field Format / Type Description
users.id INTEGER (Primary Key) Unique database account identifier.
users.api_key TEXT (Unique) Secret key formatted as xpk_ followed by 40 cryptographically random hexadecimal characters.
users.deposit_ref TEXT (Unique) Unique 8-character deposit memo reference code (e.g. XPK-7B2A) linked to your ledger balance.
users.credits REAL (Floating Point) Active request credits balance. 1 credit = 1 request clearance ($0.001 USD value).
users.has_promo INTEGER (0 or 1) Flag recording whether the 500 free promotional request package has been redeemed.

3 Authentication Protocols & Code Implementation

Pass your API key in every HTTP request. Header authentication is strongly recommended:

Python Example (requests) 
import requests

API_KEY = "xpk_your_secret_api_key_here"
url = "https://xploithubcapctha.up.railway.app/v1/unlock"

headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}

payload = {
    "url": "https://gitlab.com/users/sign_in",
    "mode": "auto",       # "auto", "stealth", "fast"
    "method": "GET"
}

response = requests.post(url, headers=headers, json=payload)
data = response.json()

if data.get("success"):
    print("Page Title:", data["title"])
    print("Cookies Captured:", data["cookies"])
    print("Execution Duration:", data["duration_ms"], "ms")
    print("Credits Remaining:", data["credits_remaining"])
else:
    print("Error:", data.get("error"))

4 HTTP Response Codes & Error Matrix

Status Code Meaning Resolution Action
200 OK Challenge successfully cleared. DOM and cookies returned in JSON body. 1.0 credit deducted.
202 Accepted Async scrape task queued. Poll /v1/tasks/{task_id} or await webhook POST.
401 Unauthorized API Key missing or invalid. Check the X-API-Key header in your request.
402 Payment Required Insufficient credits (balance < 1.0). Top up via Solana USDT or claim free 500 credits with Discord promo.
403 Forbidden Account restricted (5-hr cooldown active). Wait for cooldown period to elapse if promo link was removed.
400 Bad Request Target host refused or timeout. No credit is debited on failed challenge attempts.
